Exclusão de dados — Quase Sena

O Quase Sena não exige cadastro e não cria contas de usuário.

Como excluir os dados armazenados no aparelho

Os jogos salvos, favoritos, preferências, sequência do Número do Dia, histórico em cache e demais informações locais podem ser removidos pelo próprio usuário.

O usuário pode:

  1. Excluir jogos e informações salvas diretamente pelas opções disponíveis no Quase Sena.
  2. Limpar os dados do aplicativo pelas configurações do Android.
  3. Desinstalar o Quase Sena para remover os dados armazenados no espaço privado do aplicativo.

Arquivos já exportados, salvos ou compartilhados com outros aplicativos não são apagados automaticamente pelo Quase Sena.

Solicitar exclusão de dados

Para solicitar a exclusão de dados que estejam sob controle do desenvolvedor do Quase Sena, envie um e-mail para:

wtu38@hotmail.com

No assunto, escreva: Solicitação de exclusão de dados — Quase Sena.

Não envie senhas nem conteúdo privado desnecessário.

Dados que podem ser excluídos

Quando aplicável, serão excluídos dados fornecidos voluntariamente durante atendimento, suporte ou contato com o desenvolvedor, desde que não exista obrigação legal para mantê-los.

O Quase Sena não mantém uma conta de usuário nem sincroniza o Cofre do aplicativo com um servidor próprio na versão atual.

Dados tratados por terceiros

O aplicativo utiliza serviços e SDKs de terceiros, incluindo Google Mobile Ads e Google User Messaging Platform.

Dados processados diretamente por esses serviços são tratados conforme as políticas e os controles disponibilizados pelos respectivos fornecedores.

O desenvolvedor do Quase Sena não consegue excluir diretamente informações que estejam exclusivamente sob controle desses terceiros.

Retenção

Dados enviados voluntariamente ao desenvolvedor para suporte ou solicitações de privacidade são mantidos somente durante o período necessário para responder à solicitação, solucionar o atendimento e cumprir eventuais obrigações legais aplicáveis.

Dados armazenados localmente permanecem no dispositivo até que o usuário os exclua, limpe os dados do aplicativo ou desinstale o Quase Sena.
